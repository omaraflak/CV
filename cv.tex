% ---------------------------------------------------------------------
%  Underlined links.  The rule is drawn first and the text painted over
%  it with a white halo, so descenders punch through the line.
%  Self-contained: no ulem, no soul.  Link text must not need to wrap.
% ---------------------------------------------------------------------
\newcommand{\cvuline}[1]{%
  \begingroup
    \sbox0{#1}%
    \rlap{\raisebox{-\cvulinedepth}{\rule{\wd0}{\cvulinewidth}}}%
    \contour{white}{#1}%
  \endgroup
}
\newcommand{\link}[2]{\href{#1}{\cvuline{#2}}}

% ---------------------------------------------------------------------
%  Section heading: full-width rule, then a letterspaced label sitting
%  in the sidebar column.  Optional argument sets content beside it.
% ---------------------------------------------------------------------
\NewDocumentCommand{\cvsection}{m o}{%
  \par\addvspace{\cvsectionsep}%
  % Keep the heading with what follows.  An inline section (optional arg)
  % is self-contained and only needs room for itself; a section that opens
  % a list needs room for its first entry too.
  \IfValueTF{#2}{\Needspace*{1.5\baselineskip}}{\Needspace*{5\baselineskip}}%
  \noindent{\color{cvrule}\rule{\textwidth}{\cvrulewidth}}%
  \par\nobreak\vspace{\cvlabelsep}\nobreak
  \noindent
  \begin{minipage}[t]{\cvsidebar}\raggedright\cvsectionfont\MakeUppercase{#1}\end{minipage}%
  \hspace{\cvgutter}%
  \begin{minipage}[t]{\cvbodywidth}\raggedright\cvbodyfont\IfValueT{#2}{#2}\end{minipage}%
  \par\addvspace{\cventrysep}%
}

% ---------------------------------------------------------------------
%  Entry list.  Built on `list` rather than paired minipages so a long
%  entry can break across pages instead of overflowing the margin.
%  The date lives in the label box; body text flows normally after it.

\newcommand{\cvgobble}[1]{}

\newenvironment{cventries}{%
  \begin{list}{}{%
    \setlength{\labelwidth}{0pt}%
    \setlength{\labelsep}{0pt}%
    \setlength{\leftmargin}{\dimexpr\cvsidebar+\cvgutter\relax}%
    \setlength{\rightmargin}{0pt}%
    \setlength{\itemindent}{0pt}%
    \setlength{\listparindent}{0pt}%
    \setlength{\topsep}{0pt}%
    \setlength{\partopsep}{0pt}%
    \setlength{\parsep}{\cvparsep}%
    \setlength{\itemsep}{\cventrysep}%
    \let\makelabel\cvgobble
  }%
  \cvbodyfont\raggedright
}{%
  \end{list}%
}

% \cventry{dates}{title}[right-aligned meta]
%   followed by free-form body text until the next \cventry.
%
%   The date is set in a zero-width box flushed right into the margin, on
%   the same line as the title.  That pins it to the title's own baseline
%   — a \parbox in the list's label slot drifts when the title and the
%   body are different sizes.
\NewDocumentCommand{\cventry}{m m o}{%
  \item[]\nobreak
  \makebox[0pt][r]{%
    % Font and colour are applied OUTSIDE the parbox.  \color inserts a
    % whatsit node, and a whatsit as the first item of \parbox[t]'s \vtop
    % breaks its baseline reference: the date drops by one cap height.
    {\cvdatefont\parbox[t]{\cvsidebar}{\raggedright #1}}%
    \hspace{\cvgutter}%
  }%
  {\cvtitlefont #2}%
  \IfValueT{#3}{\hfill{\cvmetafont #3}}%
  \par\nobreak\addvspace{\cvheadsep}\nobreak
}

\cvsection{Notable Projects}

\begin{cventries}

\cventry{2026}{Building a Computer from NAND}
\link{https://notboth.dev}{notboth.dev} builds a working computer up from a single NAND
gate — logic gates, arithmetic, memory, and a CPU — one layer at a time.

\cventry{2025}{Wormhole Simulation}
\link{https://omaraflak.com/articles/wormhole}{Wormhole} simulation by ray tracing light
particles in curved spacetime, i.e.\ General Relativity.

\cventry{2025}{Mask Based Attention}
\link{https://github.com/omaraflak/mask-based-attention}{Mask-based Attention} is a research
idea I explored, whose goal is to detect the ``useful'' parts of an input for a given
prediction task, where ``useful'' is defined as ``what can't be removed so that the
prediction is still accurate''. This leads to the idea of learning a model that predicts
masks over the input.

\cventry{2025}{CUDA Tensor Library}
\link{https://github.com/omaraflak/pynn}{Pynn} is a toy tensor library developed from
scratch, with a module for training neural networks. Tensor operations run in C or within
CUDA kernels. The library has Python bindings for ease of use.

\cventry{2023}{Programming Language}
A programming language developed from scratch in C++. Despite the funky name I gave it, the
\link{https://github.com/omaraflak/banana}{Banana programming language} has a scanner,
parser, compiler, and a virtual machine.

\cventry{2022}{EIP-4671: Non-Tradable Tokens}
\link{https://eips.ethereum.org/EIPS/eip-4671}{EIP-4671} is a protocol I designed for
Non-Tradable Tokens on the Ethereum blockchain.

\cventry{2021}{YouTube Channel}
After writing articles for many years, I decided to change my medium of expression. I
started a YouTube channel in February 2021 where I program mathematical concepts, such as
neural networks, from scratch:
\link{https://www.youtube.com/@independentcode}{The Independent Code}.

\cventry{2020}{King of Ether}
\link{https://kingofether.github.io}{King of Ether} is an existing game that I reimplemented
on the Ethereum blockchain using Solidity smart contracts — the game is a Ponzi scheme in
itself. A player sends ETH to the contract to become the ``king''; anyone who wants the
throne must send 30\% more ETH, and the previous king is paid out. If nobody claims the
throne for 7 days, the game ends and the current king loses his ETH.

\cventry{2019}{Leaf}
Leaf is a device with radio capabilities that can be plugged directly into a smartphone.
People using Leaf form a \textbf{mesh network} that allows them to communicate over long
distances (up to \textbf{3~km} between each node, and by jumping through nodes for longer
distances) without any internet connection. This personal project was a proof of concept to
demonstrate possible alternatives for private decentralized communications:
\link{https://medium.com/@martin.marvin/leaf-project-natural-disaster-communication-system-1d73e8eaa7b8}{Leaf Project}.

\cventry{2018}{Machine Learning Library from Scratch}
In 2017, I decided to learn AI and more specifically the in-and-out of neural networks. I
taught myself by reading on the internet, and managed to get a strong understanding of how
neural networks work, both mathematically and programmatically. I developed a machine
learning library akin to Keras \link{https://github.com/omaraflak/my-neural-nets}{on
GitHub}. I wrote an article
\link{https://towardsdatascience.com/math-neural-network-from-scratch-in-python-d6da9f29ce65?source=friends_link&sk=2776d172d7666cc74c6b0ed292a91b0b}{on
Medium} that got published in \textit{Towards Data Science}, and gave a talk within the
organization \textit{School of AI} in Paris.

\end{cventries}
